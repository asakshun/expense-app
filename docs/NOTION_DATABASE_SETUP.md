# Notion データベースセットアップガイド

このドキュメントでは、支出管理アプリケーションで使用するNotionデータベースの作成方法を説明します。

## 概要

アプリケーションは2つのNotionデータベースを使用します：

1. **支出データベース**: 日々の支出記録を保存
2. **設定データベース**: アプリケーション設定（始まり日）を保存

## 1. 支出データベースの作成

### データベーススキーマ

| プロパティ名 | タイプ | 説明 | 必須 |
|------------|--------|------|------|
| 名前 | タイトル | レコードのタイトル（自動生成） | ✓ |
| 金額 | 数値 | 支出金額（整数） | ✓ |
| 日付 | 日付 | 支出が発生した日付 | ✓ |
| 作成日時 | 作成日時 | レコードが作成された日時（自動） | - |

### セットアップ手順

#### ステップ1: 新しいデータベースを作成

1. Notionで新しいページを作成
2. `/database` と入力して「データベース - インライン」を選択
3. データベース名を「支出記録」に変更

#### ステップ2: プロパティを設定

デフォルトで「名前」プロパティ（タイトル型）が存在します。以下のプロパティを追加します：

**金額プロパティの追加：**
1. 右上の「+」ボタンをクリック
2. プロパティ名に「金額」と入力
3. タイプで「数値」を選択
4. 数値フォーマットで「数値」を選択（カンマ区切りなし）
5. 「作成」をクリック

**日付プロパティの追加：**
1. 右上の「+」ボタンをクリック
2. プロパティ名に「日付」と入力
3. タイプで「日付」を選択
4. 日付フォーマットで好みの形式を選択（例：2024/01/01）
5. 時刻を含めるオプションは無効のまま
6. 「作成」をクリック

**作成日時プロパティの追加：**
1. 右上の「+」ボタンをクリック
2. プロパティ名に「作成日時」と入力
3. タイプで「作成日時」を選択
4. 「作成」をクリック

#### ステップ3: ビューの設定

1. 「テーブル」ビューを使用（デフォルト）
2. 「日付」列でソート（降順）を設定
   - 「日付」列のヘッダーをクリック
   - 「降順でソート」を選択

#### ステップ4: サンプルデータの追加（オプション）

テスト用にサンプルデータを追加できます：

| 名前 | 金額 | 日付 |
|------|------|------|
| ランチ | 1200 | 2024/01/15 |
| 交通費 | 500 | 2024/01/15 |
| 書籍 | 2500 | 2024/01/14 |

### データベーステンプレート（JSON）

以下は、Notion APIで使用するデータベーススキーマのJSON表現です：

```json
{
  "parent": {
    "type": "page_id",
    "page_id": "YOUR_PAGE_ID"
  },
  "title": [
    {
      "type": "text",
      "text": {
        "content": "支出記録"
      }
    }
  ],
  "properties": {
    "名前": {
      "title": {}
    },
    "金額": {
      "number": {
        "format": "number"
      }
    },
    "日付": {
      "date": {}
    },
    "作成日時": {
      "created_time": {}
    }
  }
}
```

## 2. 設定データベースの作成

### データベーススキーマ

| プロパティ名 | タイプ | 説明 | 必須 |
|------------|--------|------|------|
| 設定名 | タイトル | 設定項目の名前 | ✓ |
| 値 | 数値 | 設定値（1または25） | ✓ |
| 更新日時 | 最終更新日時 | 最後に更新された日時（自動） | - |

### セットアップ手順

#### ステップ1: 新しいデータベースを作成

1. Notionで新しいページを作成
2. `/database` と入力して「データベース - インライン」を選択
3. データベース名を「アプリ設定」に変更

#### ステップ2: プロパティを設定

**値プロパティの追加：**
1. 右上の「+」ボタンをクリック
2. プロパティ名に「値」と入力
3. タイプで「数値」を選択
4. 数値フォーマットで「数値」を選択
5. 「作成」をクリック

**更新日時プロパティの追加：**
1. 右上の「+」ボタンをクリック
2. プロパティ名に「更新日時」と入力
3. タイプで「最終更新日時」を選択
4. 「作成」をクリック

#### ステップ3: 初期データの設定

**重要**: アプリケーションが正しく動作するために、以下の初期データを必ず追加してください：

1. 新しい行を追加
2. 「設定名」に「始まり日」と入力
3. 「値」に `1` または `25` を入力（デフォルトは `1` を推奨）
4. 保存

| 設定名 | 値 |
|--------|-----|
| 始まり日 | 1 |

**注意事項：**
- 設定データベースには常に1つのレコード（始まり日）のみが存在する必要があります
- 値は `1`（月の初日）または `25`（月の25日）のみ有効です
- アプリケーションは起動時にこのレコードを読み取ります

### データベーステンプレート（JSON）

```json
{
  "parent": {
    "type": "page_id",
    "page_id": "YOUR_PAGE_ID"
  },
  "title": [
    {
      "type": "text",
      "text": {
        "content": "アプリ設定"
      }
    }
  ],
  "properties": {
    "設定名": {
      "title": {}
    },
    "値": {
      "number": {
        "format": "number"
      }
    },
    "更新日時": {
      "last_edited_time": {}
    }
  }
}
```

## 3. インテグレーションの接続

両方のデータベースを作成したら、Notionインテグレーションを接続する必要があります。

### 手順：

1. 支出データベースのページを開く
2. 右上の「...」メニューをクリック
3. 「接続」→「接続を追加」を選択
4. 作成したインテグレーション（例：「支出管理アプリ」）を選択

**同じ手順を設定データベースでも実行してください。**

## 4. データベースIDの取得

環境変数の設定に必要なデータベースIDを取得します。

### 手順：

1. データベースページを開く
2. ブラウザのアドレスバーからURLをコピー
3. URLの形式: `https://www.notion.so/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...`
4. `?` の前の32文字の英数字がデータベースID

**支出データベースID** → `NOTION_EXPENSE_DATABASE_ID`  
**設定データベースID** → `NOTION_SETTINGS_DATABASE_ID`

これらのIDを `.env.local` ファイルに設定してください。

## 5. データベースの検証

### 支出データベースの検証

以下のクエリでデータベースが正しく設定されているか確認できます：

```bash
curl -X POST https://api.notion.com/v1/databases/YOUR_EXPENSE_DATABASE_ID/query \
  -H "Authorization: Bearer YOUR_NOTION_API_KEY" \
  -H "Notion-Version: 2022-06-28" \
  -H "Content-Type: application/json"
```

### 設定データベースの検証

```bash
curl -X POST https://api.notion.com/v1/databases/YOUR_SETTINGS_DATABASE_ID/query \
  -H "Authorization: Bearer YOUR_NOTION_API_KEY" \
  -H "Notion-Version: 2022-06-28" \
  -H "Content-Type: application/json"
```

成功すると、データベースの内容がJSON形式で返されます。

## トラブルシューティング

### エラー: `object_not_found`

**原因**: 
- データベースIDが間違っている
- インテグレーションがデータベースに接続されていない

**解決**:
1. データベースURLから正しいIDを取得
2. データベースにインテグレーションを接続

### エラー: `validation_error`

**原因**: プロパティの型が期待と異なる

**解決**:
1. プロパティ名が正確に一致しているか確認（「金額」「日付」「値」など）
2. プロパティの型が正しいか確認（数値、日付など）

### 初期データが見つからない

**原因**: 設定データベースに「始まり日」レコードが存在しない

**解決**:
1. 設定データベースを開く
2. 新しい行を追加
3. 設定名: 「始まり日」、値: `1` を入力

## ベストプラクティス

1. **バックアップ**: 定期的にNotionデータベースをエクスポート
2. **アクセス制限**: インテグレーションには必要最小限の権限のみを付与
3. **データ整合性**: 設定データベースには常に1つのレコードのみを保持
4. **命名規則**: プロパティ名は正確に一致させる（大文字小文字、スペースに注意）
